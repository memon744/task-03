# 🔢 Modern Counter App

A clean and interactive counter web app built with **HTML**, **CSS**, and **JavaScript** — featuring dark mode and smooth animations.

---

## ✨ Features

- ➕ **Increment** — increase the count with one click
- ➖ **Decrement** — decrease the count (goes into negatives too)
- 🔄 **Reset** — bring the counter back to zero instantly
- 🌙 **Dark Mode Toggle** — switch between light and dark themes
- 🎨 **Glassmorphism UI** — frosted glass card with backdrop blur
- 📱 **Fully Centered Layout** — works on all screen sizes

## 🎮 How to Use

| Button | Action |
|--------|--------|
| `+` | Increases counter by 1 |
| `-` | Decreases counter by 1 |
| `Reset` | Resets counter to 0 |
| `Toggle Dark Mode` | Switches between light and dark theme |
